# Сторонние лицензии

Ядро `agenomics` использует только стандартную библиотеку Python:
сторонний код в пакет не входит и в нём не распространяется.

Необязательные зависимости ставятся пользователем отдельно
(`pip install agenomics[api]` и т.д.) и остаются под своими лицензиями:

| Пакет | Extra | Лицензия |
|---|---|---|
| fastapi | `api` | MIT |
| uvicorn | `api` | BSD-3-Clause |
| python-docx | `docx` | MIT |
| pytest | `dev` | MIT |
| httpx | `dev` | BSD-3-Clause |
| jsonschema | `dev` | MIT |

`examples/framework_evaluation/` вызывает сторонние агентные фреймворки
(LangChain, CrewAI и другие, см. `FRAMEWORK_PACKAGE` в каждом шаблоне).
Они не входят в репозиторий и в пакет, CI устанавливает их отдельно под их
собственными лицензиями. Шаблоны-адаптеры — код этого проекта.

Лицензии сверены по метаданным пакетов 25.09.2026. При добавлении новой
зависимости она вносится в эту таблицу в том же изменении.
