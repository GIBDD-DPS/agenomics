# Эталон данных: Agenomics v0.9.3 Validation Baseline

**Agenomics** · Автор: Dm.Andreyanov · Бренд: Prizolov Lab · 2026

Первая проспективная когорта Evidence Graph: предсказание делается и
замораживается до прогона, исход записывается донором после. База
фиксируется как точка отсчёта: следующие версии сравниваются с ней, а
сама она не перезаписывается.

Сразу после неё версия 0.9.4 сменила задачи у 15 шаблонов (открытые
вопросы заменены задачами с проверяемым ответом), поэтому эта база
последняя, где задачи были прежними.

## Как читать

Это разведочная когорта уровня фреймворков, а не проверка предсказательной
силы: 19 конфигураций, у каждой по два прогона, Trust Score между прогонами
почти не меняется. Сигнал по `security_incident` интересен, но 4 события
на 28 парах и интервал разницы с baseline, включающий ноль, доказательством
не являются.

## Как сохранить файл базы

Артефакт Actions удаляется через 90 дней. Файл нужно приложить к GitHub
Release, из этой среды загрузка невозможна:

```bash
# в папке, куда распакован артефакт
sha256sum frameworks_evidence.db        # записать хэш сюда, в таблицу выше
gh release create baseline-v0.9.3 frameworks_evidence.db \
  --title "Agenomics v0.9.3 Validation Baseline" \
  --notes "См. docs/baselines/v0.9.3.md" --target a9f432b
```

Без `gh`: Releases → Draft a new release → тег `baseline-v0.9.3` на коммит
`a9f432b` → приложить `frameworks_evidence.db`.
