# Contributing to Agenomics

Спасибо за интерес к методологии! Проект небольшой и на ранней стадии
(semver 0.x), поэтому процесс контрибуции пока простой.

## Сообщить о проблеме

Откройте [GitHub Issue](https://github.com/GIBDD-DPS/agenomics/issues) с:
- Что вы делали (код или запрос к API)
- Что ожидали получить
- Что получили на самом деле

Особенно ценна обратная связь о том, что веса формулы или пороги
(например, порог этического конфликта в Compatibility Score) не
соответствуют реальному поведению агентов в проде — методология
сейчас построена на экспертной калибровке, а не на статистике, и
реальные данные помогут её уточнить.

## Предложить изменение (Pull Request)

1. Форкните репозиторий, создайте ветку от `main`
2. Установите зависимости для разработки: `pip install -r requirements.txt`
3. Убедитесь, что все тесты проходят:
   ```bash
   PYTHONPATH=. pytest tests/ -v
   ```
4. Если меняете логику `trust_score.py` или `compatibility.py` —
   добавьте тест, воспроизводящий сценарий (по примеру существующих
   файлов в `tests/`)
5. Обновите `CHANGELOG.md` (раздел `[Unreleased]`, создайте если его нет)
6. Откройте Pull Request с описанием, что изменилось и почему

## Стиль кода

- Код и комментарии — на русском (уже сложившийся стиль проекта),
  идентификаторы — на английском
- Каждый публичный класс/функция — с docstring
- Изменения весов формулы или порогов — обязательно с обоснованием
  в PR (даже если это просто «показалось разумным», это стоит явно сказать)

## Версионирование

Проект использует semver, но на стадии 0.x (см. предупреждение в README)
minor-версии могут содержать breaking changes в сигнатурах. Если PR
меняет публичный API — укажите это явно в описании PR.
